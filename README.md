# HarmonyRecords
Harmony Records
Harmony Records es una aplicación web integral diseñada para la gestión operativa de una discográfica. Permite organizar el catálogo musical, administrar el roster de artistas y planificar estratégicamente los lanzamientos anuales.

Funcionalidades principales:
Catálogo de Álbumes: Visualización dinámica de álbumes con opciones de búsqueda en tiempo real, filtrado por género musical y ordenación por puntuación.

Gestión de Artistas (CRUD): Registro completo de artistas, permitiendo crear, editar y eliminar perfiles, además de controlar su estado actual (Activo, En Gira, Retirado).

Agenda de Lanzamientos: Planificador inteligente dividido por trimestres para gestionar singles, EPs, álbumes y reediciones, incluyendo control presupuestario y seguimiento de estado.

Modo Oscuro: Interfaz adaptable para mejorar la experiencia de usuario en entornos con poca luz.

Persistencia de datos: Uso de localStorage para garantizar que la información se mantenga guardada entre sesiones.

🛠️ Tecnologías utilizadas
HTML5: Estructura semántica del contenido.

CSS3: Diseño responsivo, animaciones personalizadas y sistema de temas (Light/Dark).

JavaScript: Lógica de aplicación, manipulación del DOM y persistencia de datos.
